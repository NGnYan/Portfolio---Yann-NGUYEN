React Redux REST API Swagger

Contexte

Développement front-end d'une application bancaire pour Remede Agency. L'objectif était d'intégrer le front-end avec le back-end via des appels API REST, de créer un tableau de bord utilisateur responsive et de gérer l'authentification avec Redux.

Ce que j'ai appris

Intégration d'une API REST avec React et gestion des appels HTTP
Gestion de l'authentification et des tokens avec Redux
Modélisation des routes API avec Swagger
Mise en place d'un tableau de bord utilisateur complet et responsive
